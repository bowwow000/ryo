# 現場ピン — 図面・建具管理アプリ

iPhone で図面（PDF・画像・カメラ撮影）を取り込み、扉などの位置にピンを立てて、
情報と写真をまとめて管理する現場用アプリです。
App Store や Mac は不要で、Safari で開いて「ホーム画面に追加」するとアプリとして使えます（PWA）。

## できること

| 機能 | 内容 |
|---|---|
| 現場管理 | 現場ごとに図面・項目・写真をまとめて管理。進捗（完了数／要是正数）を一覧表示 |
| 図面の取り込み | PDF（複数ページは1ページ＝1図面）、画像、カメラで紙図面を撮影 |
| 図面ビューア | ピンチで拡大・縮小、ドラッグで移動、ダブルタップで拡大 |
| ピン配置 | 「＋ピン」→ 図面をタップで扉などを登録。符号は前回の続き番号を自動入力（SD-1 → SD-2） |
| 項目情報 | 符号・種別・室名・開き方・防火・W/H・錠／金物・メーカー品番・状態・メモ（自動保存） |
| 状態管理 | 未確認／施工中／完了／要是正 をピンの色で表示。状態ごとの表示切替 |
| 写真 | その場で撮影、またはライブラリから複数選択。キャプション付け、拡大表示、共有 |
| 一覧 | 符号・室名・メモで検索、状態で絞り込み |
| 出力 | CSV（Excel 対応）、写真付きレポート（印刷／PDF 保存）、JSON バックアップ・復元 |
| オフライン | 一度開けば電波のない現場でも動作。データはすべて端末内に保存 |

## iPhone での使い方

1. 公開した URL（下記）を **Safari** で開く
2. 共有ボタン →「**ホーム画面に追加**」
3. ホーム画面の「現場ピン」アイコンから起動
4. 「＋ 新規現場」→ 図面タブで「＋ 図面を取り込む」
5. 図面を開き「＋ピン」→ 扉の位置をタップ → 情報入力・写真撮影

> **データ保存について**
> データは iPhone 内（ブラウザのストレージ）に保存されます。ホーム画面に追加して使うと保持が安定します。
> 機種変更や万一に備え、現場の「⋯」メニュー →「この現場をバックアップ」で定期的に書き出し、
> ファイルアプリや iCloud Drive に保存してください。

## 公開方法（GitHub Pages）

カメラやオフライン機能には HTTPS が必要なため、GitHub Pages での公開がおすすめです。

1. このブランチを `main` にマージ
2. GitHub のリポジトリ → **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」に設定
3. `main` に push すると `.github/workflows/pages.yml` により自動公開
   （URL 例: `https://<ユーザー名>.github.io/ryo/`）

## ローカルでの確認

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 構成

ビルド不要の素の HTML / CSS / JavaScript です。

```
index.html            画面の土台
app.js                画面・機能（ルーティング、図面ビューア、入力、出力）
db.js                 端末内データベース（IndexedDB）
styles.css            デザイン（ダークモード対応）
sw.js                 オフライン用 Service Worker
manifest.webmanifest  ホーム画面アプリ設定
vendor/pdfjs/         PDF 読み込み（pdf.js 3.11.174, Apache-2.0）
```

### 入力項目を変える

`app.js` の `FIELDS`（入力欄）・`KINDS`（種別）・`OPEN_TYPES`（開き方）・`STATUSES`（状態と色）を編集すると、
入力画面・CSV・レポートにそのまま反映されます。

> アプリを更新したら `sw.js` の `VERSION` を上げてください（端末側のキャッシュが更新されます）。
